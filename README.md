# ⚓ Морской бюджет

Простое приложение для учёта личных финансов моряка, работающего по контрактам.
Не нужно записывать каждую покупку: **раз в месяц** вносите итоговые доходы и расходы,
а приложение строит диаграммы и считает капитал.

## Возможности

- **Обзор**: статус «в рейсе / на берегу» с днями до конца контракта, чистый капитал,
  доходы и расходы, сколько удалось отложить, финансовая подушка (на сколько месяцев на берегу хватит сбережений).
- **Доходы и расходы**: один раз в месяц — доходы (зарплата, проценты, прочее) и одна общая сумма
  расходов за месяц, без разбивки по категориям. Есть кнопка «Заполнить как в прошлом месяце».
- **Контракты**: судно, компания, должность, сроки, зарплата; хронология рейсов и морской стаж.
- **Имущество**: недвижимое (квартира, дом, участок…) и движимое (авто, лодка, техника…),
  изменение стоимости к цене покупки, а также долги и кредиты.
- **Инвестиции**: криптовалюта (цены BTC, ETH, USDT и др. обновляются онлайн одной кнопкой),
  банковские депозиты (проценты считаются автоматически, с капитализацией или без), акции и фонды,
  наличные сбережения.
- **Валюты**: доллар ($ USD), гривна (₴ UAH), молдавский лей (L MDL). Каждую сумму можно вводить
  в своей валюте, всё пересчитывается в выбранную валюту. Курсы загружаются из интернета
  или вводятся вручную.
- **Диаграммы**: доходы и расходы по месяцам, источники дохода, расходы по месяцам,
  накопленные сбережения, «рейс или берег», распределение активов, капитал во времени,
  структура портфеля, хронология контрактов.
- Светлая и тёмная тема, удобно на телефоне и компьютере.

## Как запустить

Ничего устанавливать не нужно: откройте файл `index.html` в любом браузере
(Chrome, Safari, Firefox, Edge). Приложение работает **без интернета** — интернет нужен
только для обновления курсов валют и цен криптовалют.

Можно также опубликовать папку через GitHub Pages и открывать с телефона по ссылке.

Чтобы быстро посмотреть, как всё выглядит, нажмите «Посмотреть на примере».

## Где хранятся данные

Все данные хранятся **только в вашем браузере** на этом устройстве (localStorage) и никуда не отправляются.
Поэтому раз в месяц делайте резервную копию: «Настройки» → «Сохранить копию (файл)».
Файл можно загрузить обратно на любом устройстве: «Загрузить из файла».

## Структура

```
index.html      — разметка приложения
css/style.css   — оформление (светлая и тёмная темы, адаптивность)
js/charts.js    — диаграммы на SVG без внешних библиотек
js/app.js       — логика, расчёты, формы, хранение данных
```
